# Tomasulo Trainer

An interactive revision site for dynamic scheduling: Tomasulo's algorithm, hardware speculation with a reorder buffer (ROB) and commit, plus a datapath view that lights up the bus each stage uses (operation bus, operand buses, CDB, commit). You step real cronograms cycle by cycle and can fill them in yourself. It was built as a personal study aid for a computer architecture course and works in English and Spanish.

It is plain HTML, CSS and JavaScript with no build step: open `index.html`, or use the hosted version at https://joejbaldwin.github.io/tomasulo-trainer/. Progress is saved in your browser only.

This is an unofficial study tool, not course material; check anything important against your own lecture notes.
